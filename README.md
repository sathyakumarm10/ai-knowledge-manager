# AI-Ready Knowledge Manager

A Python CLI application for storing, organizing, searching, and managing structured notes.

This project is designed to become the foundation for a future AI-powered knowledge system using semantic search, embeddings, RAG, and AI agents.

## Features

- Add notes
- View all notes
- Search notes by keyword
- Organize notes by topic
- Add multiple tags
- Search notes by tag
- Filter notes by topic
- Save notes using JSON
- Load saved notes automatically
- Assign unique note IDs
- Store creation dates
- Delete notes
- Input validation

## Technologies Used

- Python
- JSON
- Git
- GitHub
